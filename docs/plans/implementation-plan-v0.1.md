# EdgeBrain V0.1 实施计划

## 当前迭代：Foundation 0

目标是建立可运行、可测试的项目基础，并通过模拟 BLE 小灯验证控制边界。真实硬件控制必须等到具体硬件 Profile 和测试设备可用后开启。

### 交付范围

1. Vue 管理端基础导航、工作台、配件页面、设备控制页面和积木自动化工作室。
2. FastAPI Core：健康检查、系统概览、配件 CRUD 最小闭环、控制任务入口。
3. Native Hardware Agent：标准 Adapter 接口和模拟 BLE 小灯。
4. 图片上传：类型、大小和安全文件名校验；本地保存元数据。
5. Core 到 Agent 的结构化控制调用，含能力白名单、超时和错误状态。
6. 后端与前端自动化测试、构建和安全检查记录。
7. Blockly Scratch 风格工作区、Automation IR 编译，以及本地 AI/规则示例生成接口。
8. 自学习基础：知识暂存、来源与置信度、审核式写入边界；不将 Hermes 作为单独页面。
9. 顶部 Bar、可收起侧栏、列表与详情独立路由、积木 JSON 导入导出。

### 暂不实现

- 真实 BLE 扫描或 GATT 写入；
- 麦克风采集、唤醒词和语音识别；
- Home Assistant 实例接入；
- ESPHome/ESP-IDF 固件；
- 采购、库存和完整待办工作流。
- 可交互 3D 装配工作台；需求已存档到 `docs/requirements/interactive-3d-workbench.json`。

### 下一迭代入口条件

- 用户提供首个 BLE 灯的品牌、型号或实物；
- 确定 macOS 首期蓝牙权限与配对体验；
- 模拟控制任务的验收测试通过；
- 配件图片和详细档案闭环可用。
- AI 生成结果只能预览，不能绕过人工确认直接运行。
